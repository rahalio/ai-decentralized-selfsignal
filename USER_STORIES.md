# Selfsignal — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Consumer

- As a consumer, I want to see which brands hold a grant and revoke one in a tap, so that “consent” is not a one-way trap.
- As a consumer, I want to download my data pack, so that portability is real.

### Publisher revenue lead

- As a publisher revenue lead, I want consented segments in my ad server, so that I can sell addressable inventory without illegal profiling.
- As a publisher revenue lead, I want yield compared to contextual-only, so that I can justify the product to the board.

### Brand media manager

- As a brand media manager, I want purpose-tagged audiences only, so that campaigns do not inherit unlawful secondary use.
- As a brand media manager, I want expired grants auto-dropped from live line items, so that compliance is not a weekly spreadsheet.

### DPO

- As a DPO, I want rights requests with SLA clocks, so that we do not miss statutory deadlines.
- As a DPO, I want processor maps per integration, so that Article 28 accountability is evidencable.
- As a DPO, I want a complaint case file that links consent history to the advertiser, so that we can respond to a supervisory authority.
